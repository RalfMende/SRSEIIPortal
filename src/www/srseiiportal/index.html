1. Connect the Z21 app

  1. Connect your smartphone or tablet to the Z21 Wifi.
  2. Open the Z21 app.
  3. In the menu, go to Settings > Z21 Settings > IP Address.
  4. Enter the following IP address: -
  5. Press Connect to Z21 again.

2. Connect the Wifi mouse

  1. Display shows SSID -> Continue with *OK button.
  2. Display shows SEARCH -> Continue with *OK button.
  3. Use the arrow keys to select the desired Wifi network.
  4. Display shows PWD -> Continue with *OK button. -
  5. Enter the Wifi password -> Continue with *OK button.

Important

The smartphone, tablet, or Wifi mouse must be connected to the same network as the Z21.

Note on the Z21 app

The Z21 app can be installed and tested free of charge. In the free version, control is limited to one locomotive. To control multiple locomotives, the full Z21 version must be unlocked through an in-app purchase.

Connect iTrain

There is one important distinction: if you have an MS2 connected to the SRSEII, iTrain uses the "Märklin Central Station 2/3" interface. Without an MS2, iTrain provides the dedicated "Gleisbox SRSEII" interface.

Option A – SRSEII with MS2

  1. Start iTrain.
  2. Open Edit → Interfaces.
  3. Add a new interface/command station.
  4. Select: "Märklin Central Station 2/3".
  5. Go to the Connection tab.
  6. Enter the following SRSEII IP address in the Host/Address field: -
  7. If available, use "Find" to search for the SRSEII on the network.
  8. Apply/save the settings.
  9. In the Specific tab, do not configure the S88 modules as external CS2 S88 modules if your feedback modules are connected directly via the CAN bus/SRSEII.
  10. Test the connection.

Option B – SRSEII without MS2

Edit → Interfaces → Type: "Gleisbox SRSEII".

Then enter the following SRSEII IP address under Connection, or use "Find" if available: -

Recommendation

If you know whether an MS2 is connected to the SRSEII or not, choose the matching option above.

Connect Win-Digipet

Win-Digipet recognizes the SRSEII as a Märklin CS2.

Step by step

  1. Start Win-Digipet.
  2. Open the settings for the digital system.
  3. Add a new digital system or edit the existing one.
  4. Select "Märklin Central Station 2 (CS2)" as the digital system/command station.
  5. Select "Network/LAN" as the connection type.
  6. Enter the following SRSEII IP address: -
  7. With older SRSEII installations, UDP may be required for Win-Digipet. In particular, older can2lan versions up to 2.26 used UDP for the special WDP communication.
  8. Test the connection.

Important: locomotive database / MFX

If you want Win-Digipet to work with the locomotive database of the SRSEII, or synchronize the vehicle data, there is an additional setting on the SRSEII itself:

In /etc/init.d/can2lan, the option -g needs to be enabled, e.g.:

can2lan -mg -c /www/config -b br-lan

This allows the SRSEII to be recognized correctly as a CS2 by Win-Digipet and enables synchronization of the locomotive database. This is not a normal Win-Digipet setting; it is a setting on the SRSEII itself.

With newer can2lan/can2udp versions from 2.27 onward, TCP can also be used for this data exchange.

Connect Rocrail

Step by step

  1. Open Rocrail.
  2. Open the Command Station / Central Properties.
  3. Create a new command station or edit the existing one.
  4. Select "Märklin CS2/CS3" or the corresponding "mbus" protocol.
  5. Enter the following SRSEII IP address as the Address/Hostname: -
  6. Use TCP as the connection type, provided your SRSEII version/configuration supports it.
  7. The CS2/CS3 port is typically 15731.
  8. Save the settings.
  9. Select this command station as the default command station in Rocrail.
  10. Restart Rocrail if necessary.
  11. Perform a simple test: press STOP/GO in Rocrail. If the connection is working, Rocrail should be able to switch the track power on and off. This is a good first test before configuring locomotives, turnouts and feedback sensors.

About SRSEII

SRSEII – Smallest Railroad Server Ever II is an open source project by Gerd (Gerhard Bertelsmann).

The project turns a suitably modified Gleisbox into a compact model railway central station. A small Linux computer connects the Gleisbox to the network and makes it possible to control the model railway through various applications and interfaces.

Among other things, SRSEII supports control via web applications, mobile devices, and various PC control programs. Interfaces such as Z21 emulation, as well as CAN and S88 connectivity, are also available.

The project's hardware and software are freely available. The project thrives not only on the original development but also on contributions, experience, and further development from the SRSEII community.
